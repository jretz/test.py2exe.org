# py2exe

py2exe is a [Python](https://www.python.org/)
[Distutils](https://docs.python.org/3/library/distutils.html) extension which
converts Python scripts into executable Windows programs, able to run without
requiring a Python installation.

Development is hosted on [GitHub](https://github.com/py2exe/py2exe). You can
find the
[mailing list](https://lists.sourceforge.net/lists/listinfo/py2exe-users),
[svn](https://sourceforge.net/p/py2exe/svn/HEAD/tree/), and
[downloads for Python 2][link-1] there.
[Downloads for Python 3](https://pypi.org/project/py2exe/) are on PyPI.

py2exe was originally developed by Thomas Heller who still makes contributions.
Jimmy Retzlaff, Mark Hammond, and Alberto Sottile have also made contributions.
Code contributions are always welcome from the community and many people provide
invaluable help on the mailing list and the Wiki.

py2exe is used by [BitTorrent](http://www.bittorrent.com),
[SpamBayes](http://spambayes.sourceforge.net/windows.html), and thousands more -
py2exe averages over 5,000 downloads per month.

In an effort to limit Wiki spam, this front page is not editable. Feel free to
edit other pages with content relevant to py2exe. You will need an account to
edit (but not to read) and your account information will be used only for the
purposes of administering this Wiki.

The old [py2exe](https://www.py2exe.org/old) web site is still available until
that information has found its way into this wiki.
